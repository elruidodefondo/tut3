4. Funciones útiles

len(), sum(), max() y min()

puntuaciones = [120, 250, 180, 300, 210] print(len(puntuaciones)) print(sum(puntuaciones)) print(max(puntuaciones)) print(min(puntuaciones))
  • len() → cantidad.
  • sum() → suma.
  • max() → valor mayor.
  • min() → valor menor.

5. Recorrer listas

Combina listas con for

Poco eficiente

print(inventario[0]) print(inventario[1]) print(inventario[2]) print(inventario[3])

Con ciclo

for objeto in inventario: print(objeto)

En cada iteración, objeto toma un elemento.

Presiona “Ejecutar for”.
6. Lista + for + if

Integra lo aprendido

puntuaciones = [40, 75, 20, 90, 55] for puntos in puntuaciones: if puntos >= 60: print(puntos, "→ nivel superado") else: print(puntos, "→ nivel no superado")
