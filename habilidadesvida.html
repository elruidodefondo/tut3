Flashcards: las 10 habilidades

🧭 Toma de decisionesToca para voltear
Toma de decisiones

Elegir una opción valorando información, consecuencias y responsabilidades.

🔎 Pensamiento críticoToca para voltear
Pensamiento crítico

Examinar información, ideas o situaciones antes de aceptarlas o tomar postura.

💡 Pensamiento creativoToca para voltear
Pensamiento creativo

Generar ideas, alternativas y soluciones nuevas o flexibles ante una situación.

🪞 AutoconocimientoToca para voltear
Autoconocimiento

Reconocer fortalezas, límites, emociones, valores, intereses y metas personales.

🗣️ Comunicación asertivaToca para voltear
Comunicación asertiva

Expresar ideas, emociones y necesidades con claridad, respeto y escucha activa.

🤝 Relaciones interpersonalesToca para voltear
Relaciones interpersonales

Crear y mantener vínculos sanos: colaborar, apoyar, respetar límites y resolver diferencias.

🧩 Solución de problemasToca para voltear
Solución de problemas

Identificar una dificultad, analizar causas y proponer acciones para resolverla.

🌦️ Manejo de emocionesToca para voltear
Manejo de emociones

Identificar y regular emociones para responder de manera adecuada, no impulsiva.

😮‍💨 Manejo del estrésToca para voltear
Manejo del estrés

Detectar fuentes de tensión y usar estrategias para afrontarlas: respiración, organización, descanso y apoyo.

💞 EmpatíaToca para voltear
Empatía

Comprender la perspectiva y emociones de otras personas para actuar con respeto y solidaridad.
