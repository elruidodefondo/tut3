🧠 2.1 · Pensamiento computacional

Este es el único repaso conceptual de los cuatro pilares. Abre cada tarjeta y recuerda para qué sirve.

🧩 Descomposición

Dividir un problema grande en partes pequeñas y manejables.

Ejemplo: separar un proyecto en investigación, diseño, materiales y exposición.

🔁 Patrones

Encontrar semejanzas o repeticiones que permiten aplicar una regla conocida.

Ejemplo: descubrir que varios cálculos siguen la misma operación.

🎯 Abstracción

Conservar la información importante y dejar fuera los detalles que no ayudan.

Ejemplo: para calcular un promedio importan las calificaciones, no el color de la mochila.

💻 CODING · Del algoritmo al programa

Coding es traducir una idea o algoritmo al lenguaje que una computadora puede ejecutar. La computadora es literal: necesita instrucciones claras y exactas.

🧭 Algoritmo

1. Pedir nombre.
2. Pedir puntos.
3. Evaluar puntos.
4. Mostrar resultado.

→

💻 Código

LEER nombre
LEER puntos
SI puntos >= 100 ...
MOSTRAR resultado

Abre las tarjetas. Aquí se concentran los conceptos de Coding; no volveremos a repetir los cuatro pilares.

🔄 Entrada–Proceso–Salida

Entrada: datos que recibe el programa.
Proceso: lo que calcula o decide.
Salida: resultado que muestra.

📦 Variables

Guardan información que el programa puede usar o cambiar, como nombre, puntos o vidas.

🚦 Condiciones

Permiten tomar decisiones.

SI puntos ≥ 100 → nivel superado.
SI NO → sigue intentando.

🔁 Bucles

Repiten acciones sin escribir el mismo código muchas veces.

Ejemplo: revisar 5 materias.

🐞 Debugging

Programar también implica detectar y corregir errores: palabras mal escritas, comillas olvidadas o signos incorrectos.

🤖 La computadora es literal

“Hazlo rápido” es ambiguo. “Repite 5 veces: avanzar 10 pasos” es preciso y ejecutable.
