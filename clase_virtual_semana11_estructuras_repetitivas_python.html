1. El problema de repetir

¿Qué harías si una acción debe ocurrir muchas veces?

Forma poco eficiente

print("El héroe entrena") print("El héroe entrena") print("El héroe entrena") print("El héroe entrena") print("El héroe entrena")

Funciona, pero sería poco práctico escribir 100 o 1,000 líneas iguales.

Con una estructura repetitiva

for vuelta in range(5): print("El héroe entrena")

Python repite el bloque 5 veces.

Concepto: una estructura repetitiva permite ejecutar un bloque de instrucciones varias veces.

2. Conceptos esenciales

Repetición, iteración y condición de término

🔁

Repetición

Ejecutar nuevamente una o varias instrucciones.

1️⃣2️⃣3️⃣

Iteración

Cada vez que el ciclo se ejecuta.

🛑

Condición de término

La regla que indica cuándo debe detenerse el ciclo.

5 repeticiones = 5 iteraciones
Todo ciclo debe tener una forma de terminar. Si la condición nunca cambia, el programa puede quedar atrapado en un ciclo infinito.

Piensa antes de continuar

Un personaje debe caminar hasta llegar a la puerta. ¿Sabemos exactamente cuántos pasos necesitará?

Sí, siempre sabemos el número exacto.
No necesariamente; conviene repetir mientras no llegue.
3. Estructura for

Usa for cuando sabes cuántas veces repetir

for vuelta in range(5): print("Vuelta número:", vuelta)
range(5) genera: 0, 1, 2, 3, 4.

Si quieres comenzar en 1:

for numero in range(1, 6): print(numero)

4. Estructura while

Usa while cuando repites mientras una condición sea verdadera

bateria = 20 while bateria < 100: bateria = bateria + 20 print("Batería:", bateria)

El ciclo continúa mientras bateria < 100.

Clave: dentro del ciclo debe ocurrir algo que acerque la condición a su final.

Simulador de carga

Presiona “Ejecutar while”.

for

Ideal cuando conoces la cantidad de repeticiones.

for i in range(5):

while

Ideal cuando repites según una condición.

6. Contadores y acumuladores

Dos patrones muy útiles dentro de los ciclos

Contador

Aumenta normalmente de uno en uno.

contador = 0 for vuelta in range(5): contador = contador + 1 print(contador)
0 → 1 → 2 → 3 → 4 → 5

Acumulador

Va sumando cantidades.

puntos = 0 for ronda in range(3): puntos = puntos + 10 print(puntos)
0 → 10 → 20 → 30

7. Debugging

Encuentra el ciclo infinito

energia = 20 while energia < 100: print("Cargando energía:", energia)

Este programa tiene un problema: la condición siempre seguirá siendo verdadera.

Falta otro print().
Falta modificar energia dentro del ciclo.
Debe cambiarse while por if.
La variable debe ser texto.

Corrección

energia = 20 while energia < 100: energia = energia + 20 print("Cargando energía:", energia)
Pregunta clave al revisar un while: ¿la condición puede llegar a ser falsa?
